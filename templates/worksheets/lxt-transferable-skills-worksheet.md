# LxT Transferable Skills Worksheet
## For Learner-Centric MOOC Design

### How to Use This Worksheet

This worksheet helps you create a **Learning Extension Trajectory (LxT)** that
also develops a **transferable skill**, such as problem decomposition or
systems thinking, that your learners will need after they graduate.

It follows the four steps of the
[LxT Constructor](../constructors/LxT_Constructor.pptx):

```
[A] Identify Trajectories → [B] Identify Resources → [C] Create Tasks → [D] Create Assimilation Quiz
```

and adds a **skill layer** to them:
- In Steps A-C, you choose a skill and design the task so learners *practise*
  it.
- Step D stays the same: the assimilation quiz only checks that learners have
  accessed the resource. An optional skill reflection prompt is added beside it.

**You will need:**
- One module or Learning Dialogue (LeD) from your course, and its objectives
- The [Transferable Skills Catalog](../../docs/transferable-skills-catalog.md)
- The [Worked Example](../../examples/lxt-transferable-skills/worked-example.md)
  (optional, but helpful the first time)

**Two levels, one worksheet:**
- **[Core]** items are required. Complete these if you are new to LCM. They
  produce one complete LxT for one learner category.
- **[Stretch]** items are optional. Try these if you have designed LxTs before,
  or if you finish the Core items early.

**Suggested time (Core path, about 1h40):**

| Part | Time |
|---|---|
| 1-3: Context and skill choice | 20 min |
| 4: Trajectories | 10 min |
| 5: Resources | 15 min |
| 6: Tasks | 15 min |
| 7: Assimilation quiz and reflection | 15 min |
| 9-10: Quality check and peer review | 25 min |

Text in `[square brackets]` is a placeholder. Replace it with something from
your own subject.

### Part 5: Identify Resources
*Constructor Steps B.1-B.2*

#### Step B.1: Search for resources

1. **[Core]** Find 1-2 resources for your trajectory. **[Stretch]** Find at
   least one resource for each prioritized category, in varied media formats.

   Resources that make a skill *visible* include:
   - an expert walking through how they solved a problem
   - a case study with a decision or a dilemma
   - a "what went wrong" story or post-mortem

### Part 6: Create Tasks with a Skill Lens
*Constructor Steps C.1-C.2*

This is the most important part. The **task** is where your learners practise
the transferable skill.

#### Step C.1: Identify the most relevant portion

1. **[Core]** For each resource, identify the portion learners must look at,
   and why. (For example: the key result in a paper, a 4-minute segment of a
   video, one section of a report.)

#### Step C.2: Create the task and the skill move

2. **[Core]** Write a specific task that makes learners use the most relevant
   portion **and** perform at least one **skill move** from your skill card's
   "Observable learner moves".

| Module | LxT Resource | Most Relevant portion (and why) | Task for learner | Skill move required |
|--------|--------------|---------------------------------|------------------|---------------------|
|        |              |                                 |                  |                     |
|        |              |                                 |                  |                     |

**Need a starting point?** Adapt a task starter from your skill card. For
example:
- *Problem Decomposition:* "Break `[a problem in your subject]` into 3-5
  smaller questions. Which one must be answered first, and why?"
- *Systems Thinking:* "If `[one element]` changes, what else changes? What
  changes *later*?"
- *Evaluating Evidence:* "`[Resource]` claims `[claim]`. What evidence does it
  give? What is missing?"

3. **[Core]** Check your task against these questions:
   - [ ] Can a learner complete it **without** using the skill? (If yes,
         revise.)
   - [ ] Does it fit the learner's expected starting level?
   - [ ] Can it be completed in a reasonable time (about 20-40 minutes)?

### Part 9: Quality Checklist
**[Core]**

From the LxT Constructor:
- [ ] Have you identified a minimum of 3 category of learners?
- [ ] Have you ensured that there is at least one resource for each cohort
      identified?
- [ ] Have you identified resources that are free/open?
- [ ] Have you created an assimilation quiz that ensures that learners have
      accessed the content?

*In this session you may build only one trajectory in full. The first two
items apply to the complete LxT you will finish later.*

For the skill layer:
- [ ] Is the skill named to learners in plain words?
- [ ] Does the task require the skill move, not just recall?
- [ ] Does the resource show the skill being used?
- [ ] Is the assimilation quiz still a simple check of access?
- [ ] (If included) Does the reflection prompt ask *how* the learner worked?
- [ ] Can learners complete the task in the time available?
