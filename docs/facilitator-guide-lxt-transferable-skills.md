# Facilitator Guide: Designing LxTs for Transferable Skills
## A 2.5-Hour Hands-On Faculty Session

### Overview

In this session, faculty who have recently been introduced to the
Learner-Centric MOOC (LCM) framework design one **Learning Extension Trajectory
(LxT)** for their own course. The trajectory deliberately develops a
**transferable skill** - a way of thinking or working, such as problem
decomposition or systems thinking, that learners will carry beyond college.

The session works for any subject. Faculty from different departments work
side by side, and that mix is part of the design.

### Session Outcomes

By the end of the session, each participant will have:
1. Explained the difference between a content objective and a transferable
   skill
2. Chosen one transferable skill that fits a module of their own course
3. Built one complete LxT (trajectory, resource, task, assimilation quiz) with
   a skill layer
4. Given and received peer feedback from a colleague in another department
5. Listed next steps to complete and launch the LxT

**Printing tip:** The Markdown files can be converted to Word or PDF (for
example, with `pandoc file.md -o file.docx`) for printing.

### Before the Session

**Ask participants to bring:**
- The outline of one module or Learning Dialogue (LeD) from a course they teach
- The learning objectives for that module
- A laptop or phone with internet access (to search for resources)

**Facilitator preparation:**
- [ ] Read the worksheet, catalog and worked example in full
- [ ] Try the Core path yourself for a subject you know (about 45 minutes)
- [ ] Print materials; optionally cut the catalog into 8 skill cards per table
- [ ] Arrange seating so each table has faculty from **different departments**
- [ ] Ask participants about their LCM experience in advance (or at the door)
      so you can pair newcomers with experienced faculty

### Run Sheet (2 hours 30 minutes)

| Time | Duration | Activity | Worksheet |
|------|----------|----------|-----------|
| 0:00 | 15 min | Opening: "The graduate in three years" | Part 2 |
| 0:15 | 20 min | Input: LxT recap and the skill layer | - |
| 0:35 | 15 min | Choosing a skill | Parts 1, 3 |
| 0:50 | 40 min | Build: trajectory, resources, task | Parts 4-6 |
| 1:30 | 10 min | Break | - |
| 1:40 | 15 min | Assimilation quiz and reflection | Part 7 |
| 1:55 | 25 min | Cross-department peer review | Parts 9, 10 |
| 2:20 | 10 min | Share-out, action items and exit ticket | Part 10 |

#### 0:00 - Opening: "The Graduate in Three Years" (15 min)

**Purpose:** Make the need for transferable skills felt before naming them.

1. **Think (3 min):** Participants answer Worksheet Part 2 individually.
2. **Pair (5 min):** Share with a neighbour from another department.
3. **Share (7 min):** Collect 5-6 answers to question 3 ("What way of thinking
   would help them most?") on the board.

**Facilitator move:** Group the board answers. You will usually see problem
solving, communication, judgement and working with others appear. Point out
that faculty from *different* subjects named the *same* needs. That is what
makes these skills transferable.

#### 0:15 - Input: LxT Recap and the Skill Layer (20 min)

**Purpose:** Connect the new idea to the LxT steps participants already know.

1. **LxT recap (5 min):** Project the constructor's overview slide. Recall the
   four steps: Identify Trajectories, Identify Resources, Create Tasks, Create
   Assimilation Quiz.
2. **The skill layer (7 min):** Explain the three changes:
   - Step A: each trajectory also targets one skill
   - Steps B-C: choose resources that *show* the skill; design the task so
     learners *use* it
   - Step D: the assimilation quiz does not change; an optional reflection
     prompt is added
3. **Walk through the worked example (8 min):** Show Parts 3, 6 and 7 of the
   Environmental Studies example. Then show the "Same Skill, Different
   Subjects" snapshots, so faculty from other disciplines see themselves in it.

**Key message:** A transferable skill is not a new topic to teach. It is how
learners work *with* your content.

#### 0:35 - Choosing a Skill (15 min)

**Purpose:** Each participant commits to one skill for one module.

1. Participants fill in Part 1 (5 min).
2. **Card sort (10 min):** Each table spreads out the 8 skill cards.
   Participants read the cards, then choose one skill and answer Part 3
   questions 2 and 3.

**Facilitator move:** Circulate and ask: "Where does an expert in your field
use this skill?" If a participant cannot answer, suggest a different skill.

#### 0:50 - Build: Trajectory, Resources, Task (40 min)

**Purpose:** Build the core of the LxT.

| Time in block | Activity |
|---------------|----------|
| 0-10 min | Part 4: list learner categories, choose one, fill the A.3 table |
| 10-25 min | Part 5: search for 1-2 resources, check "Skill visible?" and copyright |
| 25-40 min | Part 6: identify the relevant portion and write the task |

**Facilitator moves:**
- Announce each switch in the timer.
- At 25 minutes, pause the room for one minute: "Read your task. Could a
  learner finish it *without* using the skill? If yes, revise it."
- Point participants who are stuck to the task starters on their skill card.

#### 1:30 - Break (10 min)

#### 1:40 - Assimilation Quiz and Reflection (15 min)

**Purpose:** Complete the LxT and keep Step D true to the LCM design.

1. Participants write 2-3 assimilation questions per resource (Part 7).
2. Participants who finish write the optional skill reflection prompt.

**Facilitator move:** Remind the room before they begin: "The assimilation quiz
only checks that learners accessed the resource. It is a simple Recall or
Understand question. The *task* develops the skill, not the quiz."

#### 1:55 - Cross-Department Peer Review (25 min)

**Purpose:** Improve each LxT and test whether the skill is described in
language that works beyond one subject.

1. Pair participants from **different departments** (2 min).
2. Each participant self-checks with Part 9 (5 min).
3. Swap worksheets. Read the partner's Parts 3-7 (5 min).
4. Give feedback using the Part 10 table, 5 minutes per person (10 min).
5. Revise one thing based on the feedback (3 min).

**Why cross-department?** If a colleague from another subject can follow the
skill move, the skill has been described in transferable terms. If they cannot,
the "skill" may really be subject content in disguise.

#### 2:20 - Share-Out and Close (10 min)

1. Two or three volunteers share their skill, task and one piece of peer
   feedback (5 min).
2. Everyone writes three action items in Part 10 (3 min).
3. **Exit ticket (2 min):** On a sticky note: "One thing I will do with this
   LxT in the next two weeks" and "One question I still have."

### Supporting Faculty With Different Experience

| | Newer to LCM | Experienced with LCM |
|---|---|---|
| Worksheet path | **[Core]** items only | **[Core]** plus **[Stretch]** items |
| Trajectories | 1 learner category | 3-5 learner categories |
| Skills | 1 skill | Up to 2 skills, mapped across modules |
| Supports | Task starters, worked example open beside them | Part 8: connect the skill to LeDs, LbDs and LxIs |
| Role in the room | Builds with a supportive partner | Can act as a table mentor for newcomers |

**If someone finishes early:** Suggest Part 6 question 4 (a second version of
the task for a different starting level), or Part 8.

**If someone falls behind:** Help them complete Parts 3, 5 and 6 for one
resource. The rest can be finished after the session.

### Common Pitfalls and How to Redirect

| What you see | Why it is a problem | What to say |
|--------------|---------------------|-------------|
| The "skill" is a topic, for example "photosynthesis" or "balance sheets" | It is content, not a way of working | "What would learners be *doing* with photosynthesis? Which skill card matches that?" |
| The task only asks learners to summarise or recall | The skill is never practised | "Which observable move from your skill card does this task require?" |
| The assimilation quiz tests the skill | It changes the purpose of Step D and makes the quiz too hard | "Keep the quiz to a simple check that they opened the resource. Let the task carry the skill." |
| The resource is behind a paywall or login | Not all learners can access it | "Can you find an open alternative? Check open textbooks, government sites and Creative Commons repositories." |
| The resource explains the skill but never shows it in use | Learners need to see the skill applied | "Is there a case, a walkthrough or a story where someone actually uses it?" |
| The task is too long for an extension activity | Learners will skip it | "Can a learner finish this in 20-40 minutes?" |

### After the Session

- Share the worksheet and catalog files with participants.
- Suggest a follow-up check-in two weeks later to review completed LxTs.
- Encourage participants to contribute their completed trajectories as
  examples to this toolkit (see [CONTRIBUTING.md](../community/CONTRIBUTING.md)).
- Use the exit tickets to plan follow-up support.

### Appendix: Mapping to the LxT Constructor

Every step of the original
[LxT Constructor](../templates/constructors/LxT_Constructor.pptx) is kept in the
worksheet.

| Constructor step | Worksheet part | Skill layer added |
|------------------|----------------|-------------------|
| (new) Choose a transferable skill | Parts 2-3 | Skill chosen and described in plain words |
| A.1 List all possible categories | Part 4, Step A.1 | - |
| A.2 Identify modules/LeDs for LxTs | Part 1 | - |
| A.3 Prioritize the categories | Part 4, Step A.3 | Target Skill and Expected Starting Level columns |
| B.1 Search for resources | Part 5, Step B.1 | "Skill visible?" column |
| B.2 Identify copyright for resources | Part 5, Step B.2 | - |
| C.1 Identify most relevant portion | Part 6, Step C.1 | - |
| C.2 Create task for the resource | Part 6, Step C.2 | "Skill move required" column and task check |
| D.1 Create assimilation quiz | Part 7, Step D.1 | Unchanged; optional skill reflection prompt added |
| Quality checklist (4 items) | Part 9 | All 4 items kept, plus 6 skill-layer items |
| (new) Connect to other LCM elements | Part 8 | Skill revisited in LeD, LbD and LxI |
| (new) Peer review | Part 10 | Cross-department test of transferability |
